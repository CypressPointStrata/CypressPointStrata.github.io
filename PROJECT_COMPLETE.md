## 🎓 Customization Guide

### Easy Changes

**Change Primary Color:**
- Edit `assets/styles.css`
- Find `--color-primary: #d699ad;`
- Replace with your color hex code
- Affects: Buttons, links, accents throughout

**Update Organization Name:**
- Edit header in any HTML file
- Change `<h1>Cypress Point Strata</h1>`
- Change `<p>NW2050 - Community Portal</p>`

**Update Contact Email:**
- Edit in `contacts.html`
- Update all instances of cypresspointnw2050@gmail.com
- Add/remove council members as needed

**Add New Documents:**
1. Add PDF to appropriate `index_files/documents/[category]/` folder
2. Find page (e.g., minutes.html)
3. Add `<li><a href="index_files/documents/minutes/2026/filename.pdf" target="_blank">Document Name</a></li>`
4. Save file

### Advanced Customization
- See `assets/styles.css` for all variables
- Modify breakpoints (currently 768px for mobile)
- Change fonts in `body` selector
- Add new pages using existing HTML as template
